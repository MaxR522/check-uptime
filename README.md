# Check uptime

It is a little app to check if a website is healthy or not. I will build it for myself. This application should be simple and contains only minimal feature.

## Feature

- User can add website that need to be checked
- The app send a request to each website
- Send notification to the user in telegram, messenger, ... if the website is unreachable or if there is a problem.

## Stack

- Sqlite: for the database
- Go
- Templ
- Htmx
